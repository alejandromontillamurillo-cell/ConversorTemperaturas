# Conversor de temperaturas en Java

Programa sencillo en **Java** para convertir temperaturas entre Celsius y Fahrenheit. Es un proyecto formativo que separa la lógica de conversión del punto de entrada del programa.

## Funcionalidad

- Celsius a Fahrenheit: `°F = (°C × 1,8) + 32`.
- Fahrenheit a Celsius: `°C = (°F − 32) / 1,8`.
- `Main.java` ejecuta ejemplos de prueba con los valores 0 °C, 100 °C, 32 °F y 212 °F.

## Archivos

- `ConversorTemperaturas.java`: métodos estáticos de conversión.
- `Main.java`: ejemplos de uso.

## Requisitos y ejecución

Necesitas un JDK instalado. Desde la carpeta del proyecto:

```bash
javac Main.java ConversorTemperaturas.java
java Main
```

## Aprendizajes

Métodos estáticos, operaciones aritméticas, organización básica de clases y ejecución de una aplicación Java desde consola.
